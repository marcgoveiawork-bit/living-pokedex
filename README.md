# Living Pokédex

A fan-made Pokédex with realistic renders and a 3D depth effect: the image shifts with the mouse,
a finger drag, or phone tilt.

- `index.html` — the whole site (home grid + entry pages)
- `assets/` — each entry's image and its depth map
- `tools/prep_depth.py` — cleans a raw depth map before it is added
- `CLAUDE.md` — the rules every new entry follows

To view locally, serve the folder (for example `python3 -m http.server`) and open the address it prints.
